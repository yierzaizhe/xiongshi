# 宠友互助官网

这是 `宠友互助` 小程序的静态官网项目，纯 HTML/CSS/JS，无构建依赖，可直接部署到 GitHub Pages。

## 本地预览

直接打开：

```text
official-website/index.html
```

或在目录内启动任意静态服务。

## 发布到 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 将 `official-website` 目录内容推送到仓库根目录。
3. 在 GitHub 仓库里打开：

```text
Settings -> Pages
```

4. Source 选择：

```text
Deploy from a branch
```

5. Branch 选择：

```text
main / root
```

保存后等待 GitHub Pages 构建完成即可。
